# dotfiles

Personal machine setup, organized by tool. Each directory is self-contained
with its own `install.sh` and `README.md`.

- [`claude-code/`](claude-code/) — Claude Code settings, hooks, statusline, sounds, skills.
- [`zsh/`](zsh/) — Oh My Zsh + powerlevel10k config and plugins.

Secrets, auth tokens, and machine-specific hostnames/IPs are intentionally
excluded or redacted (see each directory's README) since this repo is public.
