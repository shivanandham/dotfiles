# zsh setup

Oh My Zsh + powerlevel10k, with these plugins:
`git ruby npm rails bundler jump node nvm ruby vscode zsh-autosuggestions zsh-syntax-highlighting`

## Contents

- `.zshrc` — main shell config. A few SSH aliases and an email reference have
  been redacted (`<REDACTED-*>`) since this repo is public — fill in your own
  values, or check your password manager / private notes for the originals.
- `.p10k.zsh` — powerlevel10k prompt configuration (generated by `p10k configure`).
- `install.sh` — installs Oh My Zsh, the `zsh-autosuggestions` /
  `zsh-syntax-highlighting` plugins, and the `powerlevel10k` theme, then
  symlinks the two config files into `$HOME`.

## Setup on a new machine

```sh
./install.sh
exec zsh
```

External tools `.zshrc` expects on `PATH` (not installed by this script):
`mise`, `direnv`, `jump`, `nvm`. Install these separately (e.g. via Homebrew)
before sourcing the new `.zshrc`, or comment out the corresponding lines.
